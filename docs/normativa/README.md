# Normativa — fuentes de derecho

Leyes, DFL, circulares, dictámenes y glosarios oficiales. **Esto sí es norma**:
se puede citar como fundamento de una regla del sistema.

Los `.txt` se generan desde el PDF con `pdftotext -layout`; se consultan con
`grep -n` + `sed -n` para no cargar el PDF entero.

Los reglamentos internos de establecimientos (RICE) **no están acá**: viven en
`docs/rice-modelos/` porque son ejemplos de redacción, no normativa. Ver el
README de esa carpeta.
